# SCORPIO Arena Website

Separated website files extracted from the uploaded HTML.

## Files
- `index (2).html` — main page
- `style.css` — website styles
- `script.js` — website JavaScript
- `README.md` — project notes

## Local use
Keep all files in the same folder and open `index (2).html`.

## GitHub Pages
Upload all files to a repository. For easiest GitHub Pages deployment, rename `index (2).html` to `index.html`, then enable Pages in repository Settings.
